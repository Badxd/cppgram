CppGram 1.0.0 release candidate: change record (not git history)

Base:    attached snapshot b3b48b3 (verified identical to the attached library archive).
Result:  reconciled 1.0.0 source in this archive.

This archive is not a git checkout. No commits, branches or tags were created, and nothing was pushed. The file list for
this release is in changed-files.txt (generated by a directory diff against the base).

Main changes against the base, in order of importance:
1. Plain replies: the length field is authoritative, trailing transport padding is ignored (PROXY_AUDIT.md section 7).
2. Encrypted packets: the message is located from its inner length and authenticated by msg_key (at most three extra blocks).
3. FLOOD_WAIT: per-request cancel interrupts the sleep; a wait past the request deadline is returned, not resent.
4. DC migration: DC number parsed with std::from_chars.
5. Version 1.0.0 in VERSION and client.h; VERSION is a CMake configure dependency.
6. Tests, fuzz harnesses and the consumer project for the above (see CHANGELOG.md, TEST_RESULTS.md).

Late changes in the final verification round (see reports/final-1.0.0/MANIFEST.md):
- CMake package renamed from cppgram to CppGram (CppGramConfig.cmake, CppGramTargets, lib/cmake/CppGram).
- Nine upstream tgbot-cpp Dockerfiles and the echobot-submodule example moved to reference/tgbot-cpp-upstream/.
- The 19 generated src/mtproto/schema/api_impl_*.cpp files regenerated (naming-only change); schema/SHA256SUMS.txt refreshed.
- Tool scripts given their executable bit back.
- Doxygen output moved from the source tree (doc/) to the build tree. The generated doc/ directory was deleted.
- Stale root SHA256SUMS.txt removed. The archives carry their own SHA256SUMS.txt.
- README and TEST_RESULTS.md rewritten from verified results. KNOWN_LIMITATIONS, security-review and RELEASE_NOTES updated.
